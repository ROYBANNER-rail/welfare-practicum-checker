# 사회복지현장실습 일정 검수기

실습일정표를 제출하기 전에 **총 시간·주차·배치가 지침에 맞는지** 확인하는 단일 HTML 도구입니다.

> **[→ 바로 사용하기](https://roybanner-rail.github.io/welfare-practicum-checker/)**

---

## 왜 만들었나

사회복지현장실습은 **160시간(2020년 이후 수강자) 또는 120시간**을 채워야 합니다. 그런데 일정표를 짜는 일이 생각보다 까다롭습니다.

- 1일 인정시간은 **4~8시간**, 주당 **40시간**을 넘을 수 없습니다
- 기관 운영시간 밖은 인정되지 않습니다
- 주차를 1주차·2주차로 **직접 세어 표기**해야 합니다
- 신청서에 적은 실습기간과 **일정표가 다르면 반려**됩니다

이걸 손으로 세다 보면 틀립니다. 실제로 이 도구를 만든 계기가 그것입니다 — 40일치 일정표를 검산하다 **11월 25일이 「1주차」로 잘못 적힌 것**을 발견했습니다. 제출 전에 잡았으니 망정이지, 그대로 냈으면 반려 사유였습니다.

반려되면 재작성·재제출로 **실습 시작이 밀립니다.** 기계가 세면 되는 일입니다.

## 할 수 있는 것

| 기능 | 내용 |
| --- | --- |
| **일정 자동 생성** | 시작일 + 요일별 시간 + 제외일을 넣으면 목표 시간에 맞춰 일정표를 만듭니다 |
| 총량 검산 | 총 일수·총 시간이 목표와 맞는지 |
| 1일 인정시간 | 4~8시간 범위를 벗어난 날 적발 |
| 주당 상한 | 40시간 초과 주 적발 |
| **주차 자동 계산** | 시작일 기준 7일 단위. 손으로 세다 틀리는 부분 |
| 일요일 편성 | 자동 제외 및 경고 |
| 기간 초과 | 실습가능 종료일을 넘기는지 |
| 표 복사 | 결과를 엑셀·한글에 붙여넣기 |
| 제본 체크리스트 | 서류 15종 + 반려 사유 안내 |

## 쓰는 법

1. 위 링크를 열거나 `index.html`을 내려받아 브라우저로 엽니다
2. 실습 시작일, 목표 시간, 실습가능 종료일을 넣습니다
3. 요일별 실습시간을 기관 운영시간에 맞춥니다
4. 공휴일·출석수업일 등 제외할 날짜를 적습니다
5. **일정 만들고 검사하기**를 누릅니다

### 기본값 예시

```
시작일   2026-11-09
목표     160시간
평일     18:00 ~ 22:00
토요일   11:00 ~ 15:00
제외일   2026-12-12, 2026-12-25, 2026-12-26
```

→ **40일 · 160시간 · 2026-12-28 종료 · 1~8주차**

## 개인정보를 다루지 않습니다

사회복지 현장 서류를 다루는 도구라 이 부분을 설계의 전제로 두었습니다.

- **네트워크 요청이 없습니다.** `fetch`, `XMLHttpRequest`, 외부 스크립트, 폰트 CDN 모두 사용하지 않습니다
- **저장하지 않습니다.** `localStorage`, `sessionStorage`, 쿠키를 쓰지 않습니다. 새로고침하면 입력값이 사라집니다
- **단일 파일입니다.** 외부 라이브러리가 없어 의존성 취약점이 없습니다
- **CSP로 차단합니다.** `default-src 'none'`을 선언해, 코드가 바뀌어도 브라우저가 외부 연결을 막습니다

```html
<meta http-equiv="Content-Security-Policy"
      content="default-src 'none'; style-src 'unsafe-inline'; script-src 'unsafe-inline'; img-src data:;">
```

직접 확인하시려면 브라우저 개발자도구 → Network 탭을 열고 도구를 사용해 보십시오. **요청이 한 건도 잡히지 않습니다.**

이 도구는 이름·생년월일·기관명 같은 식별 정보를 입력받지 않습니다. 날짜와 시간만 다룹니다.

제외일을 하나 빠뜨렸을 때 **종료일이 12/26으로 달라지며 즉시 드러났습니다.** 도구가 잡아야 할 종류의 오류입니다.

## 한계

- **공휴일은 내장하지 않았습니다.** 대체공휴일이 해마다 달라져 틀린 값을 넣는 쪽이 위험합니다. 직접 입력하십시오
- **교육기관마다 기준이 다를 수 있습니다.** 1일 인정시간, 주당 상한, 양식은 소속 기관 안내서를 따르십시오
- 일정 생성은 **목표 시간에 도달하면 멈춥니다.** 마지막 날 시간이 딱 맞지 않으면 경고만 띄우고 조정은 직접 하셔야 합니다
- 출근부·실습일지 내용 자체는 검사하지 않습니다. **일정 단계만** 다룹니다
